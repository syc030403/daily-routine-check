# 데일리 루틴 체크

달력으로 날짜별 루틴을 관리하고, 옆으로 넘기면 오늘 루틴을 바로 체크하는 개인용 웹앱입니다.
메뉴와 온보딩 없이 바로 쓸 수 있고, 구글로 로그인하면 폰과 웹의 기록이 동기화됩니다.

## 배포 주소

https://syc030403.github.io/daily-routine-check/

## 기능

- 첫 화면 달력 (날짜별 완료 개수 표시, 월 이동)
- 날짜를 눌러 그 날의 루틴과 계획 설정, 체크, 메모
- 루틴과 계획을 따로 추가: 루틴은 그 날부터 매일 이어지고, 계획은 그 날에만 있음 (내일 이후 날짜에도 미리 추가 가능)
- 옆으로 넘기면 오늘 루틴 화면
- 루틴마다 세부 루틴을 여러 개 추가하고 따로 체크, 버튼으로 접기/펼치기 (달력의 완료 개수는 상위 루틴만 셈)
- 지난 날짜에서 고친 루틴과, 오늘이 아닌 날짜에서 고친 세부 루틴은 그 날에만 적용
- 달력의 완료 개수는 루틴만 세고, 남은 계획은 따로 표시
- 체크/메모 자동 저장
- 구글 로그인으로 기기 간 동기화 (선택, 로그인 전 기록은 첫 로그인 때 계정으로 옮겨짐)

## 기술 스택

- 순수 HTML / CSS / JavaScript (프레임워크, 빌드 도구, npm 패키지 없음)
- 로그인/동기화: Firebase Authentication(Google), Cloud Firestore (CDN에서 SDK 로드)
- 기기 저장: 브라우저 localStorage (`routine-log`, `routine-sync-uid`)
- 배포: GitHub Pages

## 파일 구성

- `index.html` — 마크업/스타일/스크립트 전부 포함된 메인 파일
- `manifest.webmanifest` — 홈 화면 추가(PWA)용 메타데이터
- `icon.svg` — 홈 화면 아이콘

## 로컬에서 실행하기

```bash
cd daily-routine-check
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속

## 홈 화면에 추가하기

- **iPhone(Safari)**: 사이트 접속 → 공유 버튼 → "홈 화면에 추가"
- **Android(Chrome)**: 사이트 접속 → 메뉴(⋮) → "홈 화면에 추가"

## 데이터 관련 참고

- **로그인 전:** 기록은 각자의 브라우저(localStorage)에만 저장되고 동기화되지 않습니다.
- **로그인 후:** 기록은 Firestore의 `users/{uid}` 아래에 저장되고, 보안 규칙으로 본인 계정만 읽고 쓸 수 있습니다. 다만 Firebase 프로젝트 관리자는 콘솔에서 데이터를 볼 수 있습니다.
- **동시 수정:** 같은 날짜를 두 기기에서 고치면 나중에 저장한 쪽이 남습니다.
- **로그아웃:** 이 기기의 사본을 지웁니다. 계정의 기록은 남아 있어 다시 로그인하면 돌아옵니다.
- `firebaseConfig`의 값은 웹앱에 원래 공개되는 식별자이므로 코드에 포함되어 있습니다.
